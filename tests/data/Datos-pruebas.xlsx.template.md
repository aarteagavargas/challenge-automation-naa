Datos-pruebas.xlsx
==================

Coloque el archivo de datos real en esta ruta:

tests/data/Datos-pruebas.xlsx

Columnas admitidas (sin considerar la fila de encabezados):
- ID: identificador numérico del Pokémon
- Name / Nombre: nombre del Pokémon
- Abilities / Habilidades: lista opcional separada por coma o |

Ejemplo:

| ID | Name | Abilities |
|---|---|---|
| 25 | pikachu | static, lightning-rod |
| 1 | bulbasaur | overgrow, chlorophyll |
